## Uninventoried / unresolved areas

- Authentication, registration, password recovery, and onboarding: not accessible from the signed-in session; root redirected to Dashboard (E-023).
- Billing/subscription, third-party integrations, notification settings, and administrative roles beyond the visible controls: not found in inspected navigation, but remain unverified.
- Record-level edit/delete/archive behavior, deeper populated List interactions, guest access, recipient-side messaging, and some file operations remain unverified. The saved-state workflows and the exact coverage boundary are detailed in [Pass 3 results](10-functional-execution-results.md).
