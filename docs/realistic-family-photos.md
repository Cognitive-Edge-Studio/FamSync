# Realistic family photos

Six original photos were generated with the built-in `image_gen` tool for fictional FamSync content. The direction is candid US family life: ordinary homes, natural light, shared responsibility, holidays and family vacations.

| Photo | Relevant placement |
| --- | --- |
| Family planning | Landing hero, sign-in/sign-up companion panel, Family Base overview and planning topics |
| Christmas morning | Landing family-moments section; Christmas gathering and Christmas morning demo nodes |
| Thanksgiving dinner | Landing family-moments section; Thanksgiving plans and memories; family meal topics |
| Backyard birthday | Landing family-moments section; birthday picnic, birthday wishes and small celebrations |
| National-park road trip | Family Base road trips, outdoor adventures and mountain-trail topics |
| Coastal vacation | Landing closing section; first beach day and seaside demo topics |

The feature sections retain interactive examples of the product, because those explain tasks, goals, conversations, files and privacy more clearly than additional lifestyle photos. Family Base person nodes retain their illustrated avatars: occasion photos do not identify particular members.

## Files

- Original PNGs and the complete generation prompt set: `output/imagegen/us-family-photos/` (`prompts.json`).
- Optimized 640 px and 1536 px WebP versions: `apps/web/public/photos/demo/`.
- Shared image paths and descriptive alternative text: `apps/web/src/lib/family-photos.ts`.

Original assets remain available. The new files use separate names and directories, so the earlier illustrations can still be used elsewhere. Family Base content remains explicitly fictional demo data.
